# Achados visuais — Lista de Campanhas

- A miniatura de identidade visual é exibida pequena dentro de um quadro amplo e não ocupa toda a área reservada.
- Em linhas com datas longas, o bloco de indicadores de Ações, Mídias e Eventos inicia antes do término visual da data, causando sobreposição.
- A lista precisa de uma estrutura de linha com áreas verticais independentes: identificação, classificação, período, operações e avaliação.
- O usuário solicitou maior altura das linhas para dar espaço de leitura e evitar que os elementos concorram horizontalmente.
- A lista reconstruída passou a separar identificação, classificação, período, operações e nota em blocos independentes, sem sobreposição no viewport de 1280 px.
- A miniatura usa preenchimento proporcional do quadro de 72 px, enquanto a linha ganhou altura mínima de 142 px para preservar leitura diária.
- Em Cadastros, Tipos e Setores aparecem como os dois primeiros cartões do grupo Operação, com nomes curtos e acesso direto às respectivas telas.
